# 聆序（LX Music Compose）

> **一款同时具备「在线」与「本地」功能的音乐播放器** —— 既能在联网时聚合搜索并播放各大平台的在线音乐，也能离线管理你自己的歌单、收藏与播放队列。

聆序是 [洛雪音乐（lx-music-mobile）](https://github.com/lyswhut/lx-music-mobile) v1.9.1 的 Compose 多平台移植版，使用 Kotlin + Jetpack Compose 从零重写 UI 层，功能对齐原版，并带来液态玻璃（Liquid Glass）视觉风格。包名 `com.lingxu.mobile`，当前版本 `1.8.8`。

## 在线 + 本地：双模能力

### 🌐 在线能力

- **聚合音源搜索**：内置酷我、酷狗、QQ 音乐、网易云、咪咕五大平台的搜索、歌单、排行榜与热搜，支持「聚合搜索」一次检索多平台。
- **用户音源脚本**：支持导入（网络 / 文件 / 剪贴板）与导出第三方音源脚本（与原版 1:1 协议），扩展播放链接、歌词、封面获取能力；脚本运行于 QuickJS 引擎。长按已导入音源可导出备份或删除。
- **在线歌词与封面**：逐行/翻译/罗马音歌词展示，封面自动拉取与本地缓存。
- **桌面歌词**：悬浮在其它应用之上显示歌词，支持多行显示（1~8 行可调，对齐原版 `maxLineNum`），可拖动定位、轻点暂停/继续、锁定位置（需悬浮窗权限）；提供当前行 / 未播放行独立配色（对齐原版 `lyricPlayedColor` / `lyricUnplayColor`）与文字水平/垂直对齐（对齐原版 `textPosition.x/y`）。播放页「更多设置」内提供快捷开关，无需跳到设置页（对齐原版播放页 `DesktopLyricBtn`）。
- **换源 fallback**：某音源取链失败时，自动在其他音源搜索同名歌曲重试。

### 💾 本地能力

- **本地歌单管理**：新建、重命名、删除歌单，歌单内歌曲支持搜索、多选批量操作、移动与排序。
- **收藏与喜欢**：本地持久化「我喜欢」及自定义列表，无需联网即可浏览。
- **播放队列**：手动排序、移除、指定播放，支持顺序 / 列表循环 / 单曲 / 随机多种播放模式。
- **记住列表位置**：从歌单、榜单等详情页返回时停在离开前的滚动位置（对齐原版 `list.isSaveScrollLocation`，可在设置中关闭）。
- **数据备份与恢复**：收藏与歌单可导出为 JSON 文件、从备份恢复，换机或重装不丢数据。
- **本地音乐源**：通过用户音源的 `local` 分支解析本地歌曲播放地址（对齐原版 local 协议）。
- **离线设置**：主题（明暗模式 + 6 档主色）、字体大小、模糊效果、音质、歌词样式等全部本地保存。

> 说明：本项目不内置任何音源脚本，在线播放需由用户自行导入合规的第三方音源；本地歌单/收藏数据完全存于设备本地。

## 构建

构建以 GitHub Actions 云端为准：推送到 `master` 分支会自动触发 `Build APK` 工作流（含 `scripts/selfcheck.py` 静态自检），产物在对应 Run 的 Artifacts 中下载。

如需本地构建（需 JDK 17+ 与 Android SDK platform android-37）：

```bash
./gradlew assembleRelease
```

改动 `.kt` 源码后请先运行静态自检：

```bash
python3 scripts/selfcheck.py
```

## 稳定性与优化

聆序在功能对齐原版的同时，持续对源码做系统性的稳定性、性能与视觉打磨。

最近一轮（**v1.8.8**，2026-11）补齐原版缺失的 `theme.dynamicBg`「播放页动态背景」：开关位于「设置 → 基本设置」，开启后播放页顶部背景随当前封面主色生成柔和渐变，切歌时平滑过渡（320ms，遵循系统减弱动效）。取色复用现有封面缓存链路（96px 小图 + 直方图取色 + 向中灰降饱和提亮），零新增依赖、零额外网络请求，关闭时整层退化无开销；默认关闭，老用户升级观感零突变。不动播放内核、路由与音源协议。改动 5 个源码文件 + 版本号。

更早一轮（**v1.8.7**，2026-11）补齐原版播放页 `MoreBtn/DesktopLyricBtn` 的「歌词位置锁定」快捷入口：播放「更多设置」弹窗内就近提供「锁定歌词位置 未锁定/已锁定」两档，读写既有 `desktopLyric.isLock` 偏好，由 LxApp 的 Flow 监听实时同步给悬浮窗，不必再跳设置页；同弹窗的「歌词对齐」「桌面歌词」胶囊统一改用全站公共 `FilterChip`，获得按压缩放、选中态渐变、48dp 热区与读屏语义，与搜索页/设置页交互语言一致。仅改 `PlayerScreen.kt` 一处，零新增依赖，不改播放内核与音源协议。

更早一轮（**v1.8.6**，2026-11）对齐原版桌面歌词「阴影色联动」：原版 9 档主题色板中仅「黑」字档配白阴影，其余配黑阴影；移植版此前阴影写死为黑，选黑字时会「黑字 + 黑阴影」难以辨认。现按当前行颜色亮度自动切换阴影色（深色字→白阴影、其余→历史黑阴影），改色即时生效、不重建悬浮窗，亮色主题字观感零突变。仅改 `DesktopLyric.kt` 一处，零新增依赖，不改播放内核与音源协议。

更早一轮（**v1.8.5**，2026-11）补齐原版播放页桌面歌词快捷开关：原版播放页 `MoreBtn` 提供 `DesktopLyricBtn`，移植版此前只能到「设置 → 桌面歌词」操作；现在播放「更多设置」弹窗内就近提供「桌面歌词 开/关」两档胶囊，未授权时拉起系统授权页。

更早一轮（**v1.8.1**，2026-11）补齐原版桌面歌词「悬浮窗宽度」设置：对齐 `desktopLyric.width`（10~100%，默认 100%），设置页「歌词设置 → 歌词宽度」滑块可调，拖动即时生效并保留当前位置，100% 沿用历史内边距观感。沿现有「DataStore → ViewModel → 原生悬浮窗」链路实现，不改播放内核与音源协议。

上一轮（v1.4.0，2026-11）是一次覆盖正确性、性能与可访问性的综合复审：

- **正确性修复**：搜索无结果时不再误显示「搜索历史」而遮蔽空态；歌单广场加载失败不再重复渲染两遍错误文案；`fetchSync` 补齐 PUT/PATCH 带 body 的处理（此前音源脚本用这两类方法取链会抛异常失败）；版本号比较兼容大写 `V` 前缀的 tag；定时停止分钟数异常大值不再 Int 溢出导致播放被瞬间暂停。

上一轮（v1.3.8）的重点：

- **歌词手动回看不被打断**：播放页手动上滑/下滑回看歌词时，自动跟随会暂停，不再每切一句就把歌词拽回当前行；浮出「回到当前歌词」按钮可一键恢复跟随，点歌词跳转或切歌也会自动恢复。
- **长音频时长显示**：超过 1 小时的音频改用 `H:MM:SS` 显示（如播客、无损长曲、现场录音），并对异常负值做钳制，避免乱码时长。
- **搜索翻页去重请求**：搜索与「加载更多」同步置位加载标志，封住快速连点导致的重复翻页请求竞态。

上一轮（v1.3.7）的重点：

- **定时停止冷启动恢复**：重新打开 App 时按已设定的分钟数自动恢复倒计时，定时设置不再因重启丢失。
- **定时抗漂移**：倒计时改用绝对到期时间计算剩余秒数，App 退到后台被系统冻结后不再因协程延迟拉长而「定时变慢」。
- **无障碍触控热区**：迷你播放条的播放/队列按钮、播放页全部控制图标的点击热区统一到至少 48dp（图标视觉尺寸不变），播放模式标签命中区加大；同时收紧次控制间距保持视觉密度。
- **工程**：以上 `.kt` 改动全部通过 `scripts/selfcheck.py` 静态自检。

上一轮（v1.3.6）的重点：

- **歌词翻译修复**：翻译/罗马音歌词继承主歌词的 `[offset:]`，修复两者时间轴错位导致「翻译/罗马音静默不显示」的问题。
- **播放竞态收口**：清空/释放播放器时递增代号并取消在途解析协程，杜绝「清空队列后被旧请求复活」及操作已释放播放器。
- **重组性能**：设置页只订阅定时剩余秒数，不再因播放进度每 500ms 更新而整页重组；歌单同步改一次落盘，避免 O(N²) 写盘。
- **数据与并发**：原子写临时文件名带 UUID，避免并发写产生残缺 JSON；自定义超时 client 容量判断加锁。
- **UI 美化**：卡片全局按压反馈、深色模式启动不再闪白且状态栏图标极性跟随主题、歌单搜索空态、播放页错误可「下一首」恢复、无效「加入播放队列」改为「复制歌曲信息」。
- **工程**：静态自检 `selfcheck.py` 接入 CI，云端构建前先拦截低级错误。

上一轮（v1.3.5）的重点：

- **搜索竞态修复**：搜索与翻页引入 `requestSeq` 版本锁，快速切换关键词或音源时旧请求不再覆盖当前结果。
- **歌词性能**：歌词高亮定位由线性扫描改为二分查找，进度高频更新时定位更省。
- **UI 美化**：首页热搜榜前三名主色强调、字号放大，榜单层级更清晰。

更早期（v1.3.4）的重点：

- **数据安全补漏**：新建歌单 id 加随机后缀，杜绝同毫秒连续创建导致歌单互相覆盖；「不喜欢」列表引入锁与加载守卫，避免冷启动竞态覆盖已有规则。
- **资源治理**：自定义超时 HTTP client 设置容量上限，杜绝第三方音源用递增 timeout 造成的 client 无界增长。
- **UI 美化**：首页三个入口图标语义化（音源/列表/歌单各不相同）；搜索历史「清空」按钮扩大点击热区。

再往前（v1.3.3 及更早）的重点：

- **数据安全**：修复备份导入的空文件守卫（损坏/空备份不再可能清空收藏与歌单）；把损坏 JSON 隔离机制覆盖到收藏、歌单歌曲、搜索历史、上次播放、不喜欢列表等全部本地数据文件；本地列表 id 加随机后缀，杜绝同毫秒创建导致互相覆盖。
- **引擎健壮性**：JS Promise 等待加一次性守卫与取消清理，杜绝 continuation 泄漏与重复 resume；脚本定时器参数改为安全取值；HTTP 请求改为按超时复用 client（连接/线程池不再逐次新建）；SDK 销毁期间迟到 fetch 回调安全沉默。
- **播放稳定性**：队列按歌曲 id 去重，避免重复 key 导致列表崩溃；切歌后 state 更新再保存上次播放（冷启动恢复定位正确曲目）；按需解析协程切歌后不再误播旧歌；`playQueue` 取消上一次未完成的解析，快速连点不串歌；修复清空缓存会把磁盘缓存永久禁用的问题；歌词负时间戳钳制。
- **性能**：歌词视图改为只依赖行号/歌曲等必要状态，播放进度每 500ms 更新不再触发歌词全量重组；迷你播放条显隐与 tab 切换改用派生状态/一次性重置，减少重组与动画抖动。
- **设置持久化**：倍速/音量/模糊强度节流落盘补上「离开页面提交最终值」，并消除拖动过程中的滑块回弹。
- **UI 美化**：歌单详情新增加载中与空态提示、空列表禁用播放；搜索页错误提示不重复、歌单结果滚动自动隐藏迷你条；收藏页按压状态稳定。

> **在线 + 本地，双模 music player**：联网时可聚合搜索酷我/酷狗/QQ/网易云/咪咕的在线音乐（歌单、榜单、歌词、封面、换源），离线时可完整管理本地歌单、收藏、播放队列与数据备份恢复。两种能力共用同一套播放内核与液态玻璃界面，切换音源不影响本地数据。

## 与原版的关系

本项目为社区移植作品，功能逻辑对齐原版 lx-music-mobile v1.9.1，音源协议、设置键名等均与原版保持可比性，便于配置互通。**本项目不内置、不分发任何音源脚本，也不提供任何受版权保护的音乐内容**，请使用者遵守当地法律法规，仅将本项目用于个人合法音乐管理。
